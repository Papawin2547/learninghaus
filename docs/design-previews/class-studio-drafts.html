ตรวจพบวิดีโอ YouTube พร้อมฝังในบทเรียน — เมื่อผู้เรียนดูจนจบ ระบบจะเช็ก YouTube Player ENDED และบันทึกว่า เรียนจบบทนี้ (+100 คะแนน) อัตโนมัติ
