# LearningHaus: คู่มือแก้ไขโค้ด

โปรเจกต์ยังเปิดจาก `learninghaus.html` เหมือนเดิม หน้าและระบบเดิมถูกแยกออกเป็น HTML, CSS และ TypeScript ตามหน้าที่ โดย TypeScript จะรวมเป็น `dist/learninghaus.js` สำหรับเว็บแบบ static

คำศัพท์ของระบบคะแนนและความสัมพันธ์ระหว่าง Stage, Score, XP, Level และ Achievement อยู่ใน `CONTEXT.md`

## แก้ส่วนไหนที่ไฟล์ใด

| สิ่งที่อยากแก้ | ไฟล์ต้นทาง |
| --- | --- |
| ข้อความทั่วไปบนหน้าเว็บ | `learninghaus.html` ค้นหาข้อความที่เห็นบนจอ |
| สี ขนาด ระยะห่าง และการจัดหน้า | `styles/learninghaus.css` และ CSS ของ Quiz ใน `quiz-assets/quiz-flow.css` |
| คำถาม ตัวเลือก คำตอบ และคำอธิบายเมื่อผิด | `src/content/questions.ts` |
| XP ที่ได้เมื่อจบด่าน เวลาแต่ละข้อ และ XP ต่อเลเวล | `src/config/rules.ts` และ `src/domain/progression.ts` |
| ชนิดด่านที่วางแผนไว้ | `src/content/stage-catalog.ts` |
| รายการ Achievement และ prompt สำหรับสร้างภาพ | `src/content/achievement-catalog.ts` |
| ข้อมูลคะแนน Leaderboard ตัวอย่าง | `src/content/leaderboard-data.ts` |
| ปุ่มเลือกบทเรียนและการ์ด | `src/features/learn/chapter-picker.ts` |
| หน้าเรียน วิดีโอ คอมเมนต์ และแชต | `src/features/learn/lesson.ts` |
| แผนที่ด่านและเงื่อนไขปลดล็อก | `src/features/quiz/stage-progress.ts` |
| หน้าคำถาม หน้า False หน้า Score และการนับ XP | `src/features/quiz/quiz-flow.ts` |
| ชื่อ รูป ข้อมูลบัญชี และแถบเลเวล | `src/features/profile/profile.ts` |
| เมนูและการสลับหน้า | `src/features/navigation/navigation.ts` |
| เพื่อน คำขอ แชทส่วนตัว และแชทกลุ่ม | `src/features/social/social.ts` และ `server/index.mjs` |
| ข้อมูลแต่ละบัญชีในเบราว์เซอร์ | `src/config/account-storage.ts` |

ใน `questions.ts` ของ Chapter 1: `q` คือคำถาม, `a` คือตัวเลือก, `c` คือลำดับคำตอบที่ถูกโดยเริ่มนับ `0`, และ `why` คือคำอธิบายที่แสดงเมื่อตอบผิด ตัวอย่าง `c: 1` หมายถึงตัวเลือกข้อที่ 2 สำหรับ Chapter 2–8 แต่ละคู่เป็น `[คำถาม, คำตอบที่ถูก]` และเว็บสร้างตัวเลือกอื่นให้อัตโนมัติ

ไฟล์ `quiz-assets/quiz-flow.js` เก็บไว้ให้หน้า backup ใช้งานเท่านั้น หน้าเว็บหลักไม่อ่านไฟล์นี้แล้ว

กติกาปัจจุบัน: ทำครบ 10 ข้อก็จบด่าน ได้ XP 80–120 ตามความถูกต้องและความเร็วเฉพาะครั้งแรกที่จบด่านนั้น การเล่นด่านเดิมซ้ำได้ 0 XP แต่เก็บคะแนนดีที่สุดใหม่ได้ คะแนนด่านเต็ม 1,000 และใช้ Level curve ใน `src/domain/progression.ts` ปรับตัวเลข XP และเวลาได้ใน `rules.ts` ส่วนจำนวนด่านต่อบทผูกกับตำแหน่งวงกลมบนแผนที่ หากจะเปลี่ยนจำนวนด่านต้องปรับแผนที่และชุดคำถามด้วย

ถ้าเปลี่ยนกติกา XP ต่อเลเวลหลังมีคนใช้งานแล้ว ข้อมูลเลเวลที่บันทึกไว้ในเบราว์เซอร์จะไม่คำนวณย้อนหลังโดยอัตโนมัติ

## วิธีดูผลหลังแก้ไฟล์ TypeScript

เปิด PowerShell ในโฟลเดอร์ `Code` แล้วรัน:

```powershell
pnpm install
pnpm check
pnpm build
```

`pnpm install` ทำครั้งแรกหรือหลังเปลี่ยน dependencies เท่านั้น หลังแก้ TypeScript ครั้งต่อไปใช้ `pnpm check` และ `pnpm build` แล้วรีเฟรชหน้าเว็บ ไฟล์ `dist/learninghaus.js` เป็นผลลัพธ์ที่เว็บใช้งานจริง จึงเก็บไว้ในโฟลเดอร์นี้ ถ้าแก้ TypeScript แต่ไม่ build หน้าเว็บจะยังใช้โค้ดเก่า

ควรเปิดเว็บผ่าน HTTP เพื่อให้สื่อและลิงก์ไฟล์ทำงานตามปกติ ถ้าเปิดแบบ static ข้อมูลโปรไฟล์ คะแนน และความคืบหน้าจะอยู่ใน `localStorage` ของเบราว์เซอร์เดิม ระบบเพื่อนและแชทข้ามเครื่องต้องเปิดผ่านเซิร์ฟเวอร์ด้านล่าง

## เปิดระบบเพื่อนและแชทข้ามเครื่อง

ใช้ Node.js 24 ขึ้นไป เปิด PowerShell ในโฟลเดอร์ `Code` แล้วรัน `pnpm build` และ `pnpm start` เซิร์ฟเวอร์จะอยู่ที่ `http://127.0.0.1:8766/Code/learninghaus.html` ผู้ใช้เครื่องอื่นในเครือข่ายเดียวกันเข้า `http://<IPv4 ของเครื่องที่เปิดเซิร์ฟเวอร์>:8766/Code/learninghaus.html` เมื่อเครื่องและไฟร์วอลล์อนุญาตให้เชื่อมต่อพอร์ตนี้

สมัครบัญชีใหม่ด้วยอีเมลและรหัสผ่านอย่างน้อย 8 ตัวอักษร แล้วค้นหาชื่อหรืออีเมลในเมนู **Friends & Chat** ส่งคำขอ รออีกฝ่ายตอบรับ จากนั้นคุยแบบส่วนตัวหรือเลือกเพื่อนเพื่อสร้างกลุ่มได้ ข้อความและคำขอเก็บใน `server/data/learninghaus.sqlite` และส่งการอัปเดตถึงผู้ที่เปิดเว็บอยู่ทันที ฐานข้อมูลนี้ถูกกันออกจาก Git ควรสำรองไฟล์ก่อนย้ายเครื่อง

หน้า **Leaderboards** ไม่อยู่ในเมนูหลัก ปุ่ม **View stage leaderboard** จะแสดงบนหน้าคะแนนหลังทำครบ 10 ข้อเท่านั้น และตัวเลือกด่านมีเฉพาะด่านที่บัญชีนั้นจบแล้ว เมื่อใช้เซิร์ฟเวอร์จะเห็นคะแนนจริงจากบัญชีอื่นในฐานข้อมูล; ถ้าเปิดแบบ static จะเห็นเพียงคะแนนในเครื่องและข้อมูลตัวอย่าง

ข้อมูลโปรไฟล์/คะแนนเดิมในเบราว์เซอร์ยังอยู่ที่เดิมและ **ไม่ถูกย้ายเข้าบัญชีใหม่อัตโนมัติ** ข้อมูลใหม่ในเบราว์เซอร์แยกตามบัญชี ชื่อ รูป อีเมล About และ Contact links ซิงก์กับเซิร์ฟเวอร์ รหัสผ่านและการปิด/ลบบัญชีบนหน้า Profile ใช้เซิร์ฟเวอร์เมื่อเข้าสู่ระบบแล้ว ส่วน Username, เบอร์โทร, ความคืบหน้าบทเรียน และสถานะปลดล็อกด่านยังเก็บเฉพาะเบราว์เซอร์ คะแนน Leaderboard ส่งจากฝั่งหน้าเว็บ จึงต้องเพิ่มการตรวจคำตอบบนเซิร์ฟเวอร์ก่อนเปิดให้คนทั่วไปแข่งขันจริง

เซิร์ฟเวอร์นี้ตั้งใจให้ทดสอบในเครือข่ายเดียวกัน ยังไม่มี HTTPS และการกู้รหัสผ่านทางอีเมลหรือ Google sign-in อย่าเปิดพอร์ตนี้ออกสู่อินเทอร์เน็ตโดยตรง ทดสอบ API ด้วย `pnpm test:social`

## สถานะการย้ายโครงสร้าง

ไฟล์ `src/config/rules.ts`, `src/content/questions.ts`, `src/features/layout/panels.ts` และ `src/features/achievement/drag-scroll.ts` ถูกตรวจชนิดข้อมูลด้วย TypeScript แล้ว โมดูลเดิมที่เหลือยังมี `// @ts-nocheck` เพื่อรักษาการทำงานระหว่างทยอยใส่ชนิดข้อมูล คำสั่ง `pnpm check` จึงยังไม่ตรวจทุกบรรทัดในโมดูลเหล่านั้น ไฟล์ `learninghaus.pre-typescript.html` เป็นสำเนาหน้าก่อนแยกโค้ด และ `tools/` เก็บสคริปต์ที่ใช้ย้ายเพียงครั้งเดียว ไม่ต้องรันซ้ำ
